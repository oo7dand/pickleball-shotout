# Pickleball Shotout

A competitive pickleball tournament application designed to help organize and manage pickleball matches and tournaments.

## Features

- Tournament organization and management
- Match scheduling
- Player rankings
- Real-time score tracking
- Tournament brackets

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Clone the repository
```bash
git clone https://github.com/oo7dand/pickleball-shotout.git
cd pickleball-shotout
```

2. Install dependencies
```bash
npm install
```

3. Start the application
```bash
npm start
```

## Project Structure

- `index.html` - Main entry point for the web application
- `src/` - Source code directory
- `public/` - Static assets
